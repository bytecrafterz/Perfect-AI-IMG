# ---------------------------------------------------------------------------
# Computer vision dependencies - the quality gate
#
# Deliberately separate from requirements.txt so the web app can be developed
# on any machine without these.  The gate degrades to a documented "unavailable"
# verdict when they are absent (see app/gate/backends.py) - it never silently
# passes an image it could not actually check.
#
# ONNX ONLY.  Do not add torch.  Reasons, in order:
#   1. ~2 GB dependency on a machine we are keeping free
#   2. the usual cause of aarch64 build failures on the Oracle ARM target
#   3. every metric the gate needs is achievable with onnxruntime + opencv
# ---------------------------------------------------------------------------

onnxruntime==1.20.1
opencv-python-headless==4.11.0.86
scikit-image==0.25.0

# insightface is NOT pinned here on purpose - see below. Everything above
# installs from wheels on Windows with no compiler:
#     pip install --only-binary=:all: -r requirements-cv.txt
#
# That alone gives you the two checks that matter most:
#     proportions  the anti-slimming baseline   (onnxruntime + pose model)
#     hands        where generators fail most    (same requirement)
#
# insightface adds identity ("is this actually her?") and the face box the
# skin check needs. It is separate because 0.7.3 publishes NO Windows wheel -
# PyPI has only a source distribution, which compiles Cython and needs MSVC
# build tools this server does not have. Wheels exist for 0.2.1, 1.0 and
# 1.0.1, but 1.0.x is not API-compatible with the FaceAnalysis usage in
# app/gate/backends.py, so it is not a drop-in bump.
#
# Until that is resolved the gate reports identity and skin_tone as UNKNOWN,
# which is honest and does not block - see resolve_strict in app/gate/gate.py.
# RESOLVED: 1.0.1 has a Windows wheel and IS API-compatible with the
# FaceAnalysis usage in app/gate/backends.py - verified by building an
# identity centroid from her 24 photographs, which score 0.83-0.87 against it.
# Install it WITHOUT dependencies, or pip tries to replace the opencv the
# running app holds open and fails on a locked cv2.pyd:
#
#     pip install --no-deps --only-binary=:all: insightface easydict prettytable
#     python scripts/fetch_models.py          # downloads buffalo_l, ~300 MB
insightface>=1.0.1
